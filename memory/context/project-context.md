# [[project-context|Contexto del Proyecto]]

## Problema
El laboratorio registra pedidos en planillas y mensajes, provocando:
- Colisiones de turnos para el mismo equipo.
- Bloqueos indebidos por cancelaciones manuales no reflejadas.
- Imposibilidad de auditar el histórico.

## Solución Requerida
Construir una solución local, verificable y persistente con pruebas automáticas, interfaz web liviana y trazabilidad de agentes.
